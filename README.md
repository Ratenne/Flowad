# Flowad | 결론 (결 + 로드)

**목적지를 정하지 않아도, 지금 떠나기 좋은 드라이브 코스를 발견할 수 있도록.**

Flowad(결론)는 사용자의 **현재 위치를 출발점**으로 날씨, 풍경, 주행 가능 시간, 차량 조건 등을 고려해 드라이브 코스를 자동으로 추천하는 서비스입니다. 어디로 갈지 직접 검색하기보다, 오늘의 상황에 맞는 길을 발견하는 경험을 지향합니다.

## 주요 기능

- **위치 기반 코스 추천** — 현재 위치 또는 직접 선택한 출발 지역을 기준으로 후보 코스를 탐색합니다.
- **상황에 맞춘 추천** — 날씨, 풍경 취향, 이용 가능한 시간, 차량 유형과 전기차 배터리·주행거리 조건 등을 반영합니다.
- **3D 지형 미리보기** — 코스별 지형과 도로 하이라이트를 입체적으로 살펴볼 수 있습니다.
- **차량 친화적 화면** — 넓은 가로형 디스플레이와 일반 브라우저를 고려한 인터페이스를 제공합니다.
- **차량 연동 확장** — Tesla 및 현대차 Pleos 환경에서 차량 순정 내비게이션과 연결하는 방향으로 개발하고 있습니다.

## 기술 구성

| 영역 | 기술 및 구성 |
| --- | --- |
| 웹 인터페이스 | HTML, CSS, JavaScript, Three.js |
| 서버 | Java 17, Spring Boot |
| 지도·지형 데이터 | OpenStreetMap, OSRM, Copernicus DEM |
| 날씨 | Open-Meteo |
| 차량 연동 개발 | Tesla Fleet API, Pleos Android |
| 배포 관련 구성 | Docker, Cloudflare |

## 개발 현황

현재는 **개발 및 검증 단계**입니다. 웹 기반 코스 추천과 지형 미리보기, 차량용 화면 및 연동 기반을 개발하고 있습니다. 일부 거리·소요 시간·전기차 관련 값은 추정치이며, 전체 왕복 경로의 실제 도로 검증이나 실시간 교통·충전소 확인을 의미하지 않습니다.

Tesla·Pleos 실제 차량 API 연동 및 순정 내비게이션 동작은 검증이 진행 중인 범위로, 실차 지원이 완료되었다는 의미는 아닙니다.
